# Ilanot 3D · presentación pública

Esta carpeta contiene una página de presentación y una imagen de vista previa. No incluye el atlas interactivo, los datos de lectura, el modelo 3D descargable ni la fotografía de alta resolución.

La vista previa se generó a partir del proyecto Ilanot 3D. La profundidad, el color y el trazado son decisiones editoriales; no son medidas del manuscrito. Las lecturas y la identificación exacta del ejemplar siguen en revisión.
